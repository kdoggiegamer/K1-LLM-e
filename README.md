# K!(LLM)e

K!(LLM)e is an AI inference project focused on providing both a command-line interface (CLI) and a graphical user interface (GUI) for running language models.

## Goals

- Run AI models through a straightforward CLI.
- Provide a GUI for users who prefer visual workflows.
- Support K!(LLM)e Model Files (KMF).

Implementation details, supported platforms, and setup instructions will be documented as the project develops.
